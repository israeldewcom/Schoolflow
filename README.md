# SchoolFlow Android app

1. Create a new GitHub repo and upload everything in this folder (keep `.github` and `scripts`).
2. Repo > Actions > "Build SchoolFlow Android APK" > Run workflow.
3. When it is green (about 5 minutes), open the repo's Releases and download SchoolFlow.apk.
4. Install it on your phone (allow installs from your browser).

To update the app, change `www/index.html` and commit. A new APK is built each time.
